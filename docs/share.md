# Introduce SwapBoost

Use this description when sharing the project. Keep its preview status and current limits visible.

> I’m building SwapBoost, an open-source memory diagnostic CLI for Windows and Linux. It shows memory readings in a clear terminal report, offers JSON output, and can observe Linux memory-pressure signals over time. This first preview is read-only: no system tuning, no telemetry, and no claims to turn storage into RAM. There’s an illustrated setup guide and prebuilt downloads. I’d love feedback on usability and platform compatibility.
>
> https://github.com/VinayKumar-06/swapboost
